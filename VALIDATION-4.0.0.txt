Master Panel 4.0.0 - Windows stability release

Release acceptance requires the matching source build to pass every mandatory
Windows CI gate. The accepted run and checksums identify the tested package.

Required software checks:
- Portable and native Windows Go race tests, unit/integration tests and vet.
- Deferred view/controller reply, TDP draft and shared UI regressions.
- Native RTSS SDK, independent C++ slot oracle, own cleanup retry and coexistence.
- Native fonts, power capabilities, LS ABI and PresentMon lifecycle checks.
- Official optional-component download verification.
- Program Files installer/uninstaller and original-user elevated launch.
- Matching app/widget full-package updates from 3.3.4 and 3.4.2 with saved settings.

Physical Win 5 hardware is not exercised on the hosted Windows runner. Real
EC/SMU behavior, flash/vibration persistence, game rendering, actual LS displayed
FPS and Winhanced boot coexistence require device testing.

Master Panel does not erase foreign overlay data or disable Winhanced services.
No BIOS or battery charge-limit writes are added.
