# MasterPanel 1.0.0.2

Windows installer release from the owner-provided R12 Settings/Setup package.

- One Setup package for the MasterPanel Windows experience.
- Launcher/FSE, Panel and Xbox Game Bar Widget serve their respective environments.
- Available hardware controls depend on the detected device and firmware.

Download the **Setup EXE** in this release. A SHA-256 file is included to verify the download. The application source and private build workspace are not published.

## Build identification

Product release: **1.0.0.2**. The supplied installer retains internal ProductVersion **4.1.2-rc.10** and FileVersion **4.1.2.9**. Its executable bytes have not been modified. The GitHub tag follows the internal version to distinguish this build from earlier technical releases.

Older clients may exclude RC tags from update checks. Use this release's Setup download for a manual update.

## Installation

Close games and the running MasterPanel interfaces, run Setup, and follow the installer. Windows gaming-home/FSE registration remains a developer preview and is separate from Microsoft production authorization.
