Master Panel 4.0.0 - Windows x64

INSTALL / UPDATE
Exit the old Master Panel from its tray menu, then run
Master-Panel-v4.0.0-Setup.exe. The default location is
C:\Program Files\Master Panel. Setup installs both panel and matching
Game Bar widget and keeps user settings. No normal upgrade uninstall is needed.

In-app: Settings > Updates > Check for updates > Download > Update & restart.
Save work and close games before installing a full package.

OPEN
Desktop: physical Keyboard/Mouse <-> Gamepad Swap button.
Widget: Win+G > Widgets > Master Panel. Open Win+G to change settings; a pinned
widget with Game Bar dismissed is telemetry-only. LT/RT switch widget tabs.
Release held controller inputs after opening or switching focus.

POWER / FAN
Maximum TDP presets save immediately and change the slider ceiling only.
Battery: 65 / 75 / 85 W. DC: 65 / 75 / 85 / 100 / 120 W.
Defaults: battery 85 W; DC 100 W. Select TDP explicitly to apply it.
Reset selects 45 W with boost off, or the lower active source ceiling.
Plugging in never automatically increases TDP. Firmware can enforce lower limits.
Fan settings use fresh temperature/RPM samples and return to EC Auto on a fault
or resume. A software process cannot guarantee recovery after power loss.

DISPLAY / AUDIO
Color profiles use supported AMD Custom Color. Night light uses Windows control.
Windows volume/mute work independently of optional FxSound status requests.
Panel and widget use the same FxSound process for the Windows session.

CONTROLLER
Choose a source, choose its output, press Done, then Apply. Done stages an edit.
Permanent flash requires its review, backup and readback; keep power connected
and the controller attached during writes. Gyro is not included.

TOOLS
Download Mode temporarily requests 8 W, then restores the prior limit within
the active source ceiling. Sleep to Hibernate depends on Windows capabilities.
Memory Reduce runs only on demand. Lossless Scaling requires a separate Steam
installation; choose its location in Tools if automatic detection misses it.

RTSS
Choose a font/preset in the RTSS tab. Time, date and battery time are separate
fields. Displayed FG FPS is measured when available; missing readings show --.
Master Panel cleans only its own output and preserves other overlay providers.
If a duplicate bar appears with Winhanced, keep the bar visible, select
Settings > RTSS troubleshooting > Check connection, then use Open data folder
to find rtss-diagnostics.json. Closing HUD alone may leave its backend running.

COMPONENTS / SUPPORT
WebView2: full UI. PawnIO: supported hardware control. Xbox Game Bar: widget.
Settings > Components offers official optional RTSS, FxSound and PawnIO setup.
Open with Windows starts the panel and restores saved preferences at sign-in.
Settings > Report a problem creates a local diagnostic ZIP for support.
Uninstall from Windows Settings > Apps; user settings are retained.
No BIOS or battery charge-limit writes are added.
