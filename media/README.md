# MasterPanel x1.0 — GitHub images

Three 2400 × 1350 PNGs rendered from the r7 application UI:

- `masterpanel-overview.png`: Full Screen Experience and quick controls.
- `masterpanel-fse.png`: fullscreen game library and per-game profile.
- `masterpanel-panel.png`: Master, Audio and Display controls.

These are development previews using a sample library and sample sensor/activity
readings, not measured performance results or a production FSE authorization.
The interface uses source 4.1.0-dev.7; x1.0 is the upcoming release display name.

Game artwork is shown to demonstrate the game-library interface. Artwork and
trademarks belong to the respective game publishers; the images do not imply
publisher affiliation. Artwork was obtained from Steam's public asset CDN.

The local `assets/steam-artwork-provenance.json` records exact source URLs. The
public repository includes only the three finished images and this explanation,
not the fixture code, application source, accounts or private diagnostics.
