# Windows distribution

Download the Windows EXE from [Releases](https://github.com/soullegacyvn-ux/Master-Panel/releases/latest).

The Master Panel application source and build workspace are private. This repository does not contain a buildable application project.

The EXE includes notices and source for redistributed third-party modules. Save them from **Settings → Third-party licenses**; module source includes its original build workflow and license.
